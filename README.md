# Student Performance Prediction Using Artificial Neural Networks

## Project Overview

This project applies Deep Learning techniques to predict student performance using an Artificial Neural Network (ANN). It demonstrates a machine learning workflow using Python, data preprocessing, feature scaling, neural network training, regularization, and model evaluation.

The project compares a baseline neural network with an improved model designed to help reduce overfitting and improve generalization.

## Objectives

- Prepare and preprocess student performance data.
- Separate the dataset into training and testing sets.
- Scale numerical features for neural network training.
- Build and train an Artificial Neural Network.
- Improve model training using dropout and learning-rate control.
- Apply EarlyStopping and ReduceLROnPlateau.
- Evaluate model performance using a confusion matrix and classification report.

## Project Workflow

### 1. Data Loading
Load the student performance dataset and inspect its structure.

### 2. Data Preprocessing
Prepare the input features and target variable, check the dataset, and split the data into training and testing sets.

### 3. Feature Scaling
Scale the input features to support effective neural network training.

### 4. Model Development
Build a baseline Artificial Neural Network and train it on the prepared data.

### 5. Model Improvement
Use dropout regularization, early stopping, learning-rate reduction, and model checkpointing to improve the training process.

### 6. Model Evaluation
Evaluate the trained model using a confusion matrix, classification report, and other results generated by the notebook.

Model performance depends on dataset quality, the selected features, and the training procedure. The notebook's results should be interpreted in the context of the dataset and should not be assumed to generalize to every student population.
